## DESIGN DIRECTION — READ CAREFULLY
This is the most important part. The site must NOT look like a generic AI-generated template. Specifically:

- **Style: "Liquid glass" + gradient mesh / gradient morphism.** Frosted-glass cards (backdrop-blur, translucent layered panels), soft glowing gradient blobs in the background that subtly shift, smooth rounded corners, soft shadows with color bleed — think Apple's "Liquid Glass" UI language combined with warm Goa sunset/ocean tones (coral, teal, gold, deep blue gradients).
- **Feel: clean, trustworthy, premium — not flashy or gimmicky.** A first-time visitor should feel "this is a real, professional local business," not "this was generated by AI in 5 minutes."
- **Absolutely NO:**
  - No AI-generated-looking stock icon packs or emoji-style icons
  - No "sparkle" or "AI" badge stickers, no robot icons, no glowing chatbot-style widgets
  - No generic purple-gradient SaaS-template look
  - No lorem ipsum — write real, specific, human-sounding copy about Goa and the business
  - No stock photos of generic "diverse people smiling in a car" — use tasteful illustration, gradients, and the 3D car model as the primary visual instead of cheesy stock photography
- Typography should feel premium and modern (e.g., a distinctive Google Font pairing — a confident display font for headings, clean sans for body), not default system fonts.
- Every page should feel hand-designed and specific to a Goa travel business — use Goa-relevant color cues (ocean blue, sunset orange/coral, sand/gold) rather than a generic corporate palette.

## PAGES / SITE STRUCTURE

1. **Home**
   - Hero: headline, subheadline, CTA ("Book Your Ride" / "Plan a Tour"), 3D car model
   - Quick vehicle category preview (Sedan / Hatchback / SUV) with starting price
   - Quick package preview (North Goa / South Goa) with CTA to full pages
   - "Why Book With Us" section (see below)
   - Trust/social proof section (Google rating/customer interactions, years of service placeholder)
   - Footer with contact, WhatsApp/call buttons, service area

2. **Vehicles** (`/vehicles`)
   - Cards for Sedan, Hatchback, SUV
   - Each shows: capacity (e.g., 4 seats), A/C availability, ideal use case (e.g., "Best for airport transfers"), starting price (`{{PRICE_SEDAN}}` etc. as placeholders), and a "Book This" CTA

3. **Tour Packages** (`/packages`, with `/packages/north-goa` and `/packages/south-goa`)
   - Full itinerary per package: stop-by-stop list of locations with a short description of each
   - What's included (A/C car, driver, fuel, tolls — use placeholder list `{{INCLUSIONS}}`)
   - What's NOT included (entry tickets, food, etc. — placeholder `{{EXCLUSIONS}}`)
   - Pricing per vehicle type for that package (placeholder values)
   - Timing (9:30 AM–5:30 PM), duration, best time of year note
   - CTA to book this specific package

4. **Pricing** (`/pricing`)
   - Clear comparison table: vehicle type × package/route × price
   - Note about additional charges (waiting time, night charges, outstation, etc. — placeholders)

5. **Why Book With Us** (`/why-us` or homepage section, your call — recommend homepage section + dedicated page for SEO)
   - Local expertise, transparent pricing, verified driver, flexible packages, 24/7 availability, no hidden charges — write specific, human copy, not generic filler

6. **Booking / Inquiry** (`/book`)
   - Form fields: Name, Phone, Pickup Date, Pickup Time, Pickup Location, Drop Location (or "Select a Package" instead of drop location if it's a tour booking), Vehicle Type, Number of Passengers, Notes
   - On submit: validate inputs server-side, then (a) open a pre-filled WhatsApp message via `wa.me` link with all details encoded, and (b) send an email notification to the business via an API route
   - Show a clear success state confirming the inquiry was sent

7. **Contact** (`/contact`)
   - Click-to-call and click-to-WhatsApp buttons
   - Embedded Google Map (their verified location)
   - Email and phone displayed with basic obfuscation to reduce scraping
   - Business hours

8. **About** (`/about`)
   - Short, human story about RSK Tours and Travels serving Goa — write this like a real local business bio, not generic corporate text
